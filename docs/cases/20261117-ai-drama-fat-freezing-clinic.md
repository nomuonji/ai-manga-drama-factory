## 冒頭の作り: フックが本編と別に用意されている

最初の約8秒は、物語の時間の外にある **フック素材**。明るい部屋・上半身裸・かけ声とダンスで、本編（夜の寝室、静かな盗み聞き）とは照明も空気も違う。
ただし人物は本編と同じ2人（そう見える）なので、本編に切り替わっても別の動画には見えない。

冒頭は3層: ① フック素材（体型の差をひと目で、笑える動きで）→ ② 題名テロップ（この先の約束）→ ③ 本編1カット目（状況がもう始まっている）。
フック部分だけを差し替えれば、本編を作り直さずに冒頭違いの版を量産できる作り（広告の検証のしかたと合っている）。このリポジトリでは `drama.json` の `hooks` で再現できる。

## なぜ効いていそうか（仮説。成果の数字は外から見えない）

1. **本編と別のフック素材で、0秒に体型比較**: 音なしでも理解できる、体でわかる差。物語の説明を背負わないので、一番強い画だけにできる。
2. **題名テロップ＝約束**: 「寝取られる時ってこんな感じ」で、続きを見る理由（気まずさ・好奇心）をはっきり作っている。
3. **視聴者＝寝たふりの主人公**: 視聴者は主人公の耳で盗み聞きする。主人公の心の声が視聴者の気持ちを代弁する。
4. **商品は会話の答えとして出る**: 宣伝ではなく、理想の体型の人物の打ち明け話。
5. **疑いを登場人物が先に言う**: 「本当に痩せるの？」「だまされてる」を女性が言い、友人が打ち消す。広告への疑いを物語の中で処理している。
6. **申し込みの理由を段階的に積む**: 手軽さ → 価格 → 追加料金なし → 特典 → 先着。
7. **主人公が予約する**: 最後に主人公が行動して、視聴者の行動を促す。
8. **2分という長さ**: 物語が続く限り見られる、というストーリー広告の型。尺が長いので途中離脱は多いはず（仮説）。

## 真似してよい仕組み

- 本編と同じ人物で、物語の外にフック素材を作り、本編の前に付ける（差し替えて冒頭違いを量産）
- 0秒で比較を見せる／題名テロップで約束する
- 主人公＝視聴者の立場（盗み聞き・のぞき見・横で聞いている）
- 商品は理想の人物の打ち明け話として出す
- 疑いを登場人物に言わせて打ち消す
- 最後に主人公が行動する

## 真似してはいけないもの・注意

- **性的なほのめかし（寝取られ）を引きにする作りは、媒体の審査・ブランド毀損・不快感のリスクが高い。** 同じ「盗み聞き」の仕組みは、職場・友人・家族の場面でも作れる。
- 医療ダイエットの効果（「寝てるだけで○kg」）や価格（「○○万円が△円」）の言い方は、医療広告の規制にかかる可能性が高い。医療・美容・健康を扱うときは、効果の断定・費用の誤解を招く表現をしない（`docs/script-method.md` 第8節）。
- 実在の人物に似た顔を作らない。Amazon など他社のロゴを画面に出さない。
- この広告の台詞・場面・人物をそのまま使わない。
