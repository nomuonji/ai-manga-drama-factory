# 成功事例・参考事例の記録

実際に配信されて話題になった・伸びたAI動画を、**脚本の作りがわかるように1カットずつ分解して残す** 場所。
新しい脚本を書く前に、近い型の事例を1つ以上読む。

## 残し方のルール

- 1事例1ファイル（`docs/cases/<YYYYMMDD>-<短い名前>.md`）。
- 元の動画・投稿のURL、見た日、尺、見えている数字（表示回数・いいね等。見た時点の値）を書く。
- **台詞・字幕は要約か、ごく短い引用（1事例で数語〜1文程度）にとどめる。** 他人の作品なので、台本を丸ごと書き写さない。
  元の言い回しが必要なときは元動画を見る。
- 1行1カット（1コマ）で、「時刻 / 画面 / 言っていること（要約）/ そのカットの役目」を書く。
- 最後に「なぜ効いていそうか（仮説）」「真似してよい仕組み」「真似してはいけないもの（規制・不快・権利）」を分けて書く。
- 数字の裏付けがないことは「仮説」と書く。広告の成果（CVRなど）は外から見えないので、分からないと書く。
