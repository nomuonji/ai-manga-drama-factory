## 反応（返信から）

- 「やばい時の日清のCMと流れが似てる」→ 投稿者「（その会社は）たまに高いテンションでゴリ押ししたようなCMを作る」
- 「集めて！並べて！何もしない！」が一番面白い、きれいなフリとオチになっていて、言うほどわけが分からなくはない塩梅が面白い
- 投稿者: 「集めて！並べて！何もしない！」は今まで買ってきた玩具の扱いでもあるので、一周回って理にかなっている
- 「シンプルなプロンプトでも面白いものができる」「Sora 2でポンコツな動画を作っていた頃を思い出す」

## なぜ効いていそうか（仮説。成果の数字は表示・いいねしか見えない）

1. **誰でも知っている型（テレビCM）を本気でやっている**: 爆発で始まる → 商品が出る → 実演 → 後光の決めカット → 大きな商品名 → 決め台詞。中身がでたらめでも、型が分かるので見ていられる。
2. **中身は誰も狙っていない**: 唇・鳥居・寿司・冷蔵庫・和室の組み合わせは、人間が考えたら「狙いすぎ」になりそうだが、AIが勝手に出したので作為が見えない。
3. **最後の一言だけ妙に筋が通る**: 「集めて！並べて！何もしない！」は意味がないのに、コレクションを買って飾るだけの人の行動に当てはまってしまう。わけが分からないだけで終わらない。
4. **投稿されたのは当たり**: 何本作ったかは分からない。当たりだけが見えている可能性が高い。

## 真似してよい仕組み

- 型（テレビCM・通販番組など）だけを渡し、中身を生成AIに任せる → `tools/gacha/gacha.py`、`catalog/gacha-formats.json` の `tv-cm` と `free`

## 真似してはいけないもの・注意

- この動画の映像・商品名・決め台詞をそのまま使わない。
- 実在の企業名・商品名・CMを真似たことが分かる要素を入れない（「〇〇のCMっぽい」と言われるのは型が伝わった結果であって、特定の会社のCMを再現しない）。
- 何本作ったか分からない動画を「1本で当たる」と考えない。ガチャの当たり率は自分たちで測る。
