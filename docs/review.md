# 仕上がりの確認

技術的に動いた（CIが通った、動画ファイルができた）ことと、見られる作品になったことは別。報告は3つに分けて書く。

- **technical**: 生成・描画・書き出しが通ったか
- **review**: 自分（エージェント）が見て確認したこと
- **human / audience**: 人の評価、公開後の数字（まだなら「未確認」と書く）

## 見る順番

1. `first-frame-phone.png` — スマホの大きさ、音なしで、何が起きているか分かるか
2. `contact-sheet.jpg`（1秒ごと）— 毎秒、何か新しく見えているか。止まっている区間はないか
3. コマ絵・キーフレーム全部
4. 動画を最初から最後まで、音ありで

## チェック項目

- [ ] 同じ人物が同じ顔・髪・服に見える
- [ ] 手・指・小道具・商品の形と使い方が正しい
- [ ] 絵の中に変な文字・ロゴ・透かしがない（あればそのコマを作り直す）
- [ ] フキダシが顔や大事なところを隠していない、画面からはみ出していない
- [ ] スマホの画面UI（上部・下部・右側のボタン）で大事な文字が隠れない
- [ ] 声がキャラに合っている、商品名・数字を正しく読んでいる
- [ ] 台詞・BGM・効果音の重なりやコマ切り替えに違和感がない
- [ ] 脚本の「広告の注意チェック」を満たしている

声を自分で聞けない環境では「音は未確認」と明記し、人に確認を頼む。

## 直し方

コマ番号（`p4`）やカット番号（`s03`）と、変えたい内容を具体的に書いて、その部分だけ直す。
生成物はプロンプトのハッシュでキャッシュされるので、変えたコマ・カットだけが作り直される。
