# 作り手の暗黙知（見る順番・数字・感覚）

動画を作り慣れた人が、言葉にしないままやっている判断を書き出したもの。手順は playbook、ここは **なぜそうするか** と **どこを見るか**。
品質の最終判断は人（Yuto）の評価。ツールの検査が通ったことは「出せる」ことの確認であって、面白いことの証明ではない。

## 1. 作業のループ — 小さく作って、見て、直す

1. 脚本と設計書だけで尺を出す（`check`）。
2. ダミー絵で配置を見る（`placeholders` → `inspect`）。
3. ダミー絵で動画にして、1秒ごとのコマ送り（`contact-sheet.jpg`）を見る。
4. ここで分かる問題を全部直してから、お金のかかる生成に進む。
5. 生成後は、絵 → コマ送り → 動画（音あり）の順で見る。
6. **1回の修正で直す原因は1つ。** 直したら同じものを見比べる。

## 2. 1枚を見るときの順番（上で引っかかったら下は見ずに直す）

1. **スマホの大きさで1秒見て、何の話か言えるか**（`first-frame-phone.png`）。
2. **視線が最初に行く物は1つか**（顔、効果音、吹き出しのどれか1つ）。
3. **文字が読めるか**: 吹き出しの文字は 1080 幅で 34px 以上。字幕は縁取り付き。
4. **スマホのUIで隠れないか**: 下 18%、上 4%、右下のボタン列（x>0.86, y>0.5）。`inspect` が検査する。
5. **人物**: 顔が切れていない／吹き出し・字幕が顔にかかっていない／前のコマと同じ人に見える。
6. **前のコマから何が新しくなったか**。答えられなければそのコマはいらない。

## 3. 脚本の感覚

- **1コマ目は事件の最中から。** 説明（「ある日の会社で」）から始めない。
- **悩みは言葉より絵で。** 「薄毛」と書かずに頭頂部を見せる、「猫背」と書かずに窓に映った姿を見せる。見る人が自分で気づくほうが刺さる。
- **他人の目を入れる。** 笑われる・比べられる・噂される。
- **主人公の心の声＝視聴者の気持ち。** 驚き・疑い・決心を主人公の心の声に言わせる。
- **疑いは登場人物が先に言う。** 「それ本当？」「だまされてない？」を誰かに言わせ、答えさせる。
- **商品は答えとして出す。** 宣伝の台詞を書かない。「実はさ…」で十分。
- **最後は行動か引き。** 主人公が申し込む／「▼このあと…▼」。まとめや説明の言い直しで終わらない。
- **狙いすぎない。** オチのために足した小道具や決め台詞、わざとらしい言い回しは嫌われる。場面とキャラが元からそうであるだけで起きる面白さを使う。
- 台詞は話し言葉で、1つの吹き出しに情報1つ。

## 4. テンポの数字

| 項目 | 値 |
|---|---|
| VOICEVOX（speed 1.12〜1.15）の話す速さ | 約 8 モーラ/秒 |
| 声なしの推定と実際の声の長さ | **実際は推定の約1.3倍**。推定で尺を決めるときは1.3倍して考える |
| 吹き出し1つの表示 | 声の長さ＋0.2秒前後 |
| コマ1つ | 1.5〜4秒。6秒以上同じ画は止まって見える |
| 予告型の漫画 | 8〜20秒 |
| 1本で完結する漫画 | 30〜60秒 |
| ドラマ1カット | 4〜8秒 |
| ドラマ全体 | 30〜120秒（長いほど高い） |

長すぎるときは、台詞を削る前に `bubble_gap`・`panel_hold`・`reveal_seconds` を詰める。それでも長ければコマを削る。

## 5. 画面の作り

- 縦長の画面は横幅が狭い。人物は中央寄りに。2人並べるなら `split` の2コマに分けるほうが顔が大きく見える。
- 見せ場のコマは大きく（`height` 1.2〜1.4、`full`）。つなぎのコマは小さく。
- 1ページに顔のアップを2つ以上並べるときは、向きを変える（左向き・右向き）。
- 吹き出しは顔の無い側・上側。しっぽは話す人へ。読む順（上→下）と話す順を合わせる。
- 効果音は1ページ1〜2個。全部のコマに付けるとうるさい。

## 6. 音

- 大事な順: 声 → 効果音 → BGM。BGM は 0.08〜0.12（声の邪魔をしない）。
- 効果音は画が動くところにだけ。驚かせる大きな音は1本に1回まで。
- 最終の音量はツールが -15 LUFS 前後にそろえる。
- **自分の耳で聞いていない限り「聞いた」と報告しない。** 測った数字は聞いた代わりにならない。聞けない環境なら「音は未確認」と書いて人に頼む。

## 7. AIの絵・動画のくせ

- 同じ人を描かせても少しずつ変わる。見本（キャラ見本）を全コマに渡すのはそのため。それでも変わるコマは作り直す。
- 文字を描かせると崩れた日本語になる。だから文字は全部ツールで描く。
- 手・指、物の持ち方、スマホの画面は崩れやすい。写さない構図にするのが一番確実。
- 動画AIは長い・複雑な動きで顔が崩れる。1カット1動作・5秒が安全。
- 日本語の固有名詞（商品名）の発音は間違えやすい。ひらがなにするか、VOICEVOX の声にする。

## 8. 報告の仕方

1. できたもの（動画・リンク）を先に。
2. technical（検査の結果・尺・費用）と、内容の評価（人の判断待ち）を分ける。
3. 自分で見て気になった点と、直さなかった理由。
4. 確かめていないこと（音を聞いていない、商品の形を確認していない等）を隠さない。
