# ガチャ工場 — 「なんかわけのわからない動画作って」で当たりを出す仕組み

## なぜこの仕組みなのか

参考: https://x.com/AI_Illust_000/status/2122681990638187006 （2026-11-17。投稿者は動画AIに「なんかわけのわからない動画作ってよ」と頼んだだけと書いている。表示4.3万、いいね約660。使ったAIは明かしていない）

15秒の謎の家電CM。爆発 → 唇の付いた紫の箱に鳥居 → 回転する寿司 → つまみを回す手 → 後光 → 大きな商品名テロップ → 和室。ハイテンションな声と、意味がないのに妙に筋が通ったキャッチコピー。

この面白さは、ほとんどが次の3つから来ている（仮説）:

1. **動画AI自身**: テレビCMの型（爆発・後光・商品名・決め台詞・テンポ）を覚えていて、絵・声・テロップを一度に出す。
2. **本数**: 1本で当たるとは限らない。投稿されるのは当たりだけ。
3. **選ぶ目**: 当たりを見分けて出す人がいる。

エージェント（Claude など）が「面白い中身」を自分で書き込むと、説明的・狙いすぎになって外れやすい（本人評価で何度も起きた失敗。`docs/craft.md`「狙いすぎない」）。
だからガチャ工場では、**エージェントは中身を考えない**。やることは3つだけ:

| エージェントの仕事 | 道具 |
|---|---|
| 引き出し方（番組の型・指示のゆるさ・モデル）を変えて何本も作らせる | `gacha.py plan` / `run` |
| 人が一気に選べる形にする（動画＋1秒ごとのコマ送り＋声の文字起こし） | `gacha.py review` → `index.html` |
| どの条件から当たりが出たかを記録し、次は当たりやすい条件に多く賭ける | `gacha.py rate` / `stats`（次の plan に自動で反映） |

## 使い方

1. GitHub Actions の **Gacha (text-to-video)** を手動実行する。本数（既定8）と上限金額（既定$15）を決める。
   - 中で `plan`（何を作るか決める）→ `run`（生成）→ `review`（一覧ページ）が順に動く。
   - `gacha/<batch-id>/batch.json` がブランチに保存され、動画と一覧ページは artifact に入る。
2. artifact の `index.html` を開いて全部見る。人が「良い／ボツ」を一言で決める。
3. エージェントが記録する: `python3 tools/gacha/gacha.py rate <batch-id> c03 pass "これは笑った"`（`pass` / `partial` / `fail`）。`gacha/ratings.jsonl` をコミットする。
4. `python3 tools/gacha/gacha.py stats` で、型・書き方・モデルごとの当たり率が見える。次の `plan` は当たり率の高い条件に多く配分しつつ、まだ試していない条件も試す（Thompson sampling）。

手元で何を作るかだけ確かめる（お金はかからない）: `python3 tools/gacha/gacha.py plan --n 8 --budget 15`

## 引き出し方（catalog/gacha-formats.json）

- **型（formats）**: 謎商品のテレビCM、深夜の通販番組、地方局の自主制作CM、教育番組、ニュース速報、天気予報、古い取扱説明ビデオ、邦画の予告編、特撮のOP、会社紹介ビデオ、料理番組、完全おまかせ。
- **書き方（styles）**: `loose`（型だけ。中身は全部AI）／`format`（型＋長さ・言語・テンポ）／`seeded`（型＋ランダムな物と場所を2つ）。
- **完全おまかせ（free）** は、評価が3件たまるまで毎回1本は必ず入れる。参考事例と同じ頼み方なので、比べる基準になる。
- 型を足すときは、なるべく実際に伸びた動画で見た型にし、`seen_in` に URL を書く。**中身（オチ・台詞）は書かない。**

## 守ること

- 実在の企業名・商品名・有名人・キャラクターを出さない（`guardrails` が毎回プロンプトに付く）。
- 当たりを公開するのは人が決める。エージェントは投稿しない。
- 1本ずつの自己採点で当たりを決めない。合否は人の評価だけ。
- 外れでも理由を推測で書かない。人の言葉をそのまま `rate` に残す。

## My Portal の道場

この作り方は My Portal のチャット用スキル `unaimed-ideation`（狙わない発想）で、道場 `unaimed-ideation`（狙わない発想道場）が本人の評価の合格率で鍛えている。
評価を `gacha.py rate` で記録したら、My Portal につながるエージェントは同じ評価を道場の trial にも記録する（つながらないエージェントは `gacha/ratings.jsonl` だけでよい。後でつながるエージェントが移す）。
